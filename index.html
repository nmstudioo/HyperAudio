Gates (per preset, at 48 and 44.1 kHz): RIFF/IEEE-Float32/stereo header, no NaN/Inf, peak ≤ 0 dBFS, tail RMS ≤ −90 dBFS and tail peak ≤ −80 dBFS over the last 2048 frames, IIR↔FIR difference ≤ 0.25 dB at log-spaced landmarks, filter centres and DC (DC values below −90 dB count as equal), and headroom margin ≥ the preset safety margin (0.50 dB for fits). Margin is −(peak magnitude response of the exported impulse, preamp included, 20 Hz–20 kHz), shown unrounded to 3 decimals and compared without rounding. The fitter, this audit, the registry and the download all use that one measurement. The limiter figure is the fixed ceiling (−1.0 dBFS IEM, −0.5 dBFS speaker) minus that same peak response, and the load-time check confirms each Master v2.0 script carries its ceiling.

Scope: browser-side math only; it does not test native RootlessJamesDSP behavior. Headroom is the peak sine-wave gain, not a bound for arbitrary broadband peaks.

Chain order is convolver, then Liveprog: the impulse does the EQ, the script does dynamics, tone and safety. The two Master v2.0 scripts and the two DDC files belong to that setup, and their limiter ceilings are fixed: −1.0 dBFS for the IEM, −0.5 dBFS for the speaker. The two S+ scripts are standalone, built for use outside the convolver, Liveprog and DDC setup. Descriptions and values below are read from the file contents. Harmonized setup

Standalone (S+)

AutoEQ fitterFit a new profile from a measurement

Forward greedy selection: for each candidate (fc, Q) the gain is the single-filter least-squares projection of the current residual, and the candidate with the lowest residual is kept; then four passes of ±step coordinate descent adjust gains only (fc and Q fixed). This is not a joint least-squares solve. Constraints: ≥ 0.4 octave between any two centres, ≥ 0.8 octave between a boost and a cut (anti-cancellation), ±12 dB gain, Q 0.5–6, fc/Q ≥ 12 Hz (so the 8192-tap IR can represent the filter), speaker fc ≥ 308 Hz. RMS and max error are measured on 220 log-spaced points, 20 Hz–20 kHz, against the 1 kHz-normalized full filter response (fixed HPF + PEQ), preamp excluded. For the speaker a second RMS covers ≥ 250 Hz; residual bass error comes from the fixed 220 Hz 2nd-order high-pass. Fits are computed at 48 kHz and appear as profiles in the workspace; each export is audited at its own sample rate. Preamp is the least attenuation (never a boost), in 0.001 dB steps, whose exported impulse meets the 0.50 dB safety margin at both 44.1 and 48 kHz, using the same headroom measurement as QA.
